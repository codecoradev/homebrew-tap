# Contributing to codecoradev/homebrew-tap

Thanks for your interest! This tap is small and mostly automated.

## What you can contribute

- Formula improvements (install layout, caveats, test block)
- CI/automation fixes
- Documentation fixes

## Important: the formula is generated

`Formula/uteke.rb` is regenerated by [`scripts/update_formula.py`](scripts/update_formula.py)
on every Uteke release. **Do not edit the formula by hand** — your change will be
overwritten. Instead, change the template in `scripts/update_formula.py` and
regenerate:

```bash
python3 scripts/update_formula.py --version X.Y.Z --checksums checksums-sha256.txt
```

## Local validation

```bash
brew tap codecoradev/tap "$PWD"
brew style codecoradev/tap/uteke
brew audit --strict --formula codecoradev/tap/uteke
brew install codecoradev/tap/uteke && brew test codecoradev/tap/uteke
```

## Conventions (CodeCora org standard)

- Branches: `fix/...`, `feat/...`, `docs/...`, `chore/...`, `ci/...`
- Commit messages & PR titles: [Conventional Commits](https://www.conventionalcommits.org/)
- PRs require a filled template (What / Why / Testing)
- External contributors must sign the [CodeCoraDev CLA](https://codecoradev.github.io/cla/) — CI checks this automatically
